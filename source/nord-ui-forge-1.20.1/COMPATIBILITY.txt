THE DEEP NIGHT UI 1.1.1 - MODPACK UI AUDIT
Source: ../modpack-mod-list.txt, all eight screenshot sections reviewed.
The list is a transcription, with truncated filenames; it is not an installed-instance scan.
The in-game F7 > Detected UI Mods page checks the actual running Forge mod list.

DEDICATED INTEGRATIONS
Iron's Spells 'n Spellbooks 1.20.1-3.16.1
  E > SPELLS opens a separate inscription tab. An equipped Curios spellbook
  appears automatically; another book can be placed in BOOK. Select a spell,
  take its EXTRACT scroll, put a replacement in SCROLL, then select the empty
  spell slot and press INSCRIBE SCROLL. This consumes a real scroll. Locked
  spells remain locked. There are eight visible spell buttons per page, with
  arrows for larger books. Native duplicate-spell rules and InscribeSpellEvent
  cancellation hooks remain in force, including hooks used by skill addons.
  Unspent scrolls return on close, and the equipped book stays in Curios.
  The portable tab is enabled by default. Server owners can turn it off or
  require a nearby inscription table in <world>/serverconfig/nordui-server.toml.
  Native spell selection, spell wheel, cooldowns, cast progress, recasts,
  targeting, screen effects, keys and addon spells are not replaced.
  The default Hotbar-anchored spell cluster docks to the left-center while
  Deep Night owns the HUD. Its original renderer, fading, selection and
  cooldown shading are retained. Custom anchors stay untouched; F7 can
  turn docking off. This avoids overlapping the themed mana and XP bars.
  Optional themed mana uses Iron's synchronized mana and max-mana attribute,
  and respects Iron's Always / Contextual / Never display setting.

Curios 5.14.1+1.20.1
  Native accessory screen, live equipment previews and return button retained.
  No accessory slot definitions, tags or equipment validators are changed.

TrashSlot 15.1.5 / Balm 7.3.38
  Registered layouts for inventory, vault and spell screens. The trash slot
  sits beside the panel and uses TrashSlot's own deletion, undo, dragging,
  keybind and JEI exclusion behavior. Existing user positions remain intact.
  TrashSlot must also be on the server for its normal functionality.

JEI 15.20.0.132
  Inventory and vault automatically use their compact layouts, leaving room
  for recipe sidebars. All are real AbstractContainerScreens with accurate
  dimensions and native slots/tooltips. Toggle reserveJeiSpace to restore the
  large layouts. RECIPES / MODS (R in compact mode) opens the original recipe
  book and other mods' InventoryScreen-only buttons. JEI owns its controls.

RPG-HUD 3.13
  AUTO detects mod ID rpghud and yields health, food, XP, armor, air, mount,
  jump, compass and hotbar rendering to it. Deep Night's inventory/vault remain usable.
  For the full Deep Night HUD, disable RPG-HUD's rendering in its own settings
  and choose DEEP_NIGHT in F7. OTHER_MOD leaves original overlay events intact.

Jade 11.13.2
  Native tooltips remain enabled. The compass stays 12 GUI pixels from the
  top, without the previous 64-pixel Jade and 24-pixel Iron's offsets.
  F7 > Compass height still adjusts its position for custom overlay layouts.

ParCool 3.4.3.3
  Automatic spacing lifts survival bars above the default stamina area.
  ParCool continues to render its own stamina and action indicators. Hunger
  remains food; it is never presented as ParCool stamina. Extra lift and
  hotbar offsets are available for custom ParCool layouts.

The remaining listed worldgen, structures, creatures, equipment and libraries
have no dedicated UI adapter here. Their tooltips/overlays and custom screens
use the same preserved paths. Unknown or truncated filenames are not treated
as confirmed APIs. This UI update does not repair loader/version mismatches or
the duplicate FTB Library versions visible in the screenshot list.

OPTIONS AND INSTALLATION
F7 in game, the inventory UI button, or Mods > The Deep Night > Config.
Client options are saved in config/nordui-client.toml. Iron's own overlay
positions remain editable in its config. No other mod's config is overwritten.
Install the same 1.1.1 jar on client and server; remove the older Deep Night jar.
Optional mods are not bundled, and the mod still runs without any of them.
See verification/VERIFICATION.txt for the exact executed test profiles.
